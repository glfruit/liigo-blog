## 为什么是命令行

IDE 里的 AI 插件解决的是"写代码时"的问题，而命令行工具解决的是"写代码前后"的问题：批量重构、跑测试、整理数据、生成报告。Claude Code 的价值不在补全，而在**它能接管一整个任务**。

## 安装与认证

```bash
npm install -g @anthropic-ai/claude-code
claude
```

首次运行会引导完成认证。之后在任何项目目录里敲 `claude`，它就接管了当前目录的上下文。

## 第一个值得跑的任务

不要从"帮我写个函数"开始——那是 IDE 插件的活。试试这个：

```
扫描这个仓库里所有的 Python 脚本，找出其中重复出现三次以上的代码模式，
把最重复的三个重构成公共函数，放在 shared/ 目录下。
```

一个小时的观察重点：它如何读文件、如何决定改动范围、如何在不确定时向你确认。理解它的决策方式，比记住任何提示词技巧都重要。

## 三条立竿见影的使用纪律

1. **先让它读，再让它改**：大改动前先要求"只输出分析，不要动文件"
2. **任务粒度控制在一屏话以内**：描述超过一屏的任务，先拆再派
3. **重要改动前手动 commit**：它的回滚能力不如你的 git 历史可靠
